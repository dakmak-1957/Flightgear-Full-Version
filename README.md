## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Advanced Flight Dynamics** — Choose from three primary flight dynamics models: JSBSim, YASim, and UIUC, providing a realistic flying experience.
- **Extensive Global Coverage** — Access over 20,000 detailed airports and a highly detailed world map featuring cities and geographical landmarks.
- **Dynamic Time Simulation** — Experience day and night cycles with accurate positions of the sun, moon, and stars.
- **Custom Aircraft Modeling** — Design and model your own aircraft, including interactive 3D cabins, using user-friendly tools.
- **Low System Requirements** — FlightGear runs smoothly on a variety of hardware configurations, making it accessible to everyone.

### Advanced Features:
- **Community Contributions** — Engage with a vibrant community that continuously enhances the software with new features and updates.
- **Cross-Platform Compatibility** — Although primarily for Windows, FlightGear supports various platforms, allowing for a wider user base.
- **Educational Applications** — Ideal for pilot training, academic research, and simulations in aerospace engineering.
